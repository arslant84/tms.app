================================================================================
REQUEST LISTS - BUTTON & TYPOGRAPHY STANDARDS
================================================================================

OVERVIEW:
---------
This document defines the unified button and typography standards applied 
across all request list pages to ensure visual consistency.

================================================================================
BUTTON STANDARDS
================================================================================

HEADER "CREATE NEW" BUTTONS:
-----------------------------
Property              | Value                    | Notes
---------------------|--------------------------|---------------------------
Class                | btn btn-primary          | Bootstrap primary button
Min-width            | 200px                    | Fixed minimum width
Padding              | 0.625rem 1.25rem         | 10px 20px
Font-size            | 1rem                     | 16px
Font-weight          | 500                      | Medium weight
White-space          | nowrap                   | Prevents text wrapping
Icon class           | bi bi-plus-circle me-2   | Bootstrap icon with margin
Icon size            | 1.125rem                 | 18px

EXAMPLE HTML:
<button class="btn btn-primary" (click)="navigateToCreate()">
  <i class="bi bi-plus-circle me-2"></i>New Request
</button>

BEFORE vs AFTER:
----------------
BEFORE: Button widths varied based on text length
  - "Create New TSR" = ~150px
  - "New Visa Application" = ~180px
  - "New Transport Request" = ~200px
  
AFTER: All buttons have consistent 200px minimum width
  - All buttons = 200px minimum (can expand if text is longer)

OVERRIDE APPROACH:
------------------
Global styles in styles.scss override component-specific styles to ensure
consistency. This means:
1. Component SCSS files can define base styles
2. Global unified styles take precedence for standardization
3. Future list pages automatically inherit unified styling

MAINTENANCE:
------------
To modify button or typography standards:
1. Update values in frontend/src/styles.scss (lines 251-338)
2. Changes automatically apply to all request list pages
3. No need to modify individual component files
