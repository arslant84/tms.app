- Icon: <i class="bi bi-plus-circle me-2"></i>
- Icon size: 1.125rem (18px)

          </button>

- Page title (h1): 1.875rem (30px), font-weight: 700
- Card titles (h3): 1.125rem (18px), font-weight: 600

- Empty state title: 1.125rem (18px), font-weight: 600
- Empty state description: 0.875rem (14px), color: #6b7280

**Icon Spacing Standard:**
- All icons in buttons use me-2 class for consistent right margin
- Format: <i class="bi bi-icon-name me-2"></i>

**No Duplicate Buttons:**
- Only ONE "Create New" button per page (in header section)
- Empty states no longer have duplicate create buttons

**Empty State Standard:**
- Icon size: 4rem (64px)
- Title size: 1.125rem (18px)
- Description size: 0.875rem (14px)
- Padding: 4rem 1.5rem
- Max-width for text: 32rem (for readability)
