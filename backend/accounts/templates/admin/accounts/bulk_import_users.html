CSV format
  • Header row required: staff_number,name,email,password,department
  • staff_number, password, and department may be left blank per row.
  • Rows left without a password get an unusable password — the user must use "forgot password" on first login.
  • department must match an existing department's name exactly (case-insensitive). Unrecognized department names are left blank rather than failing the row.
  • A row is skipped (not an error) if a user with the same name, email, or staff number already exists.
